# 🎬 CinePick - 캔바(Canva) 감성 영화 추천 웹 애플리케이션 (공식 포스터 전편 수록)

React와 Tailwind CSS를 활용해 캔바(Canva) 특유의 산뜻한 틸-퍼플 그라데이션과 함께, **40편 전편 실제 공식 극장 개봉 포스터**가 적용된 완성형 영화 큐레이션 웹 애플리케이션입니다.

## 🖼️ 주요 특징

1. **40편 전편 실제 공식 영화 포스터 적용 (장르별 10편)**
   - 일반 스톡/더미 이미지가 아닌, 각 영화의 **실제 공식 극장 개봉 포스터**를 100% 탑재했습니다.
   - `no-referrer` 정책을 적용하여 외부 이미지 차단 없이 선명하고 안정적으로 고화질 포스터를 불러옵니다.
   - **액션 (10편)**: 존 윅 4, 탑건: 매버릭, 매드맥스: 분노의 도로, 다크 나이트, 미션 임파서블: 데드 레코닝, 글래디에이터, 어벤져스: 엔드게임, 범죄도시 4, 아저씨, 분노의 질주: 더 얼티메이트
   - **코미디 (10편)**: 극한직업, 에브리씽 에브리웨어 올 앳 원스, 엑시트, 데드풀과 울버린, 트루먼 쇼, 그랜드 부다페스트 호텔, 청년경찰, 백 투 더 퓨처, 수상한 그녀, 라라랜드
   - **드라마 (10편)**: 기생충, 오펜하이머, 쇼생크 탈출, 포레스트 검프, 그린 북, 헤어질 결심, 죽은 시인의 사회, 서울의 봄, 원더, 인생은 아름다워
   - **SF (10편)**: 인터스텔라, 듄: 파트 2, 인셉션, 아바타: 물의 길, 매트릭스, 그래비티, 마션, 블레이드 러너 2049, 컨택트, 엣지 오브 투모로우

2. **캔바(Canva) 브랜드 컬러 & 모던 UI 디자인**
   - 시그니처 틸-퍼플 그라데이션 (`#00c4cc` → `#5b40e7` → `#7d2ae8`)
   - 산뜻하고 쾌적한 캔버스 배경 (`#f8fafd`) 및 파스텔톤 오로라 효과
   - 둥근 3XL 화이트 카드 (`rounded-3xl`, 소프트 섀도우) 및 장르별 맞춤 컬러 뱃지
   - 클릭 시 영화 상세 시놉시스, 감독, 출연진을 확인할 수 있는 인터랙티브 모달

3. **오늘의 랜덤 영화 추천 (셔플링 룰렛 인터랙션)**
   - 1.2초간 카드가 빠르게 돌아가는 셔플링 룰렛 애니메이션 후 당첨 영화 발표
   - 큐레이터 추천 한줄평 + "🎲 다시 뽑기" 기능 지원
